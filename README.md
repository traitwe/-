# MCM 2026 数学建模

这是一个用于竞赛数学建模的独立 Python 项目骨架。

## 竞赛建模经验总结

- 先分析题目的实际机理、数据来源和约束，再选择模型；不为使用算法而使用算法。
- 每一问应明确输入、决策变量、目标函数、约束条件和输出，并让前一问结果服务后一问。
- 优化问题优先保证模型可解释、约束完整、方案可执行，再考虑复杂求解算法。
- 数据驱动问题需要完整的数据预处理、特征选择、模型对比和评价指标；避免只报告单一模型的准确率。
- 至少进行一种可信验证：误差分析、敏感性分析、交叉验证、情景扰动或基准模型对比。
- 图表和表格应直接支撑结论；摘要要说明问题、方法、关键数值结果和最终建议。
- 高分论文的关键是形成“数据—模型—结果—验证”的闭环，而不是堆叠 PCA、神经网络、遗传算法等工具。
