# 封稿前一致性与边界检查清单

本清单用于最终提交前核对，不代表当前模型失效，也不要求在没有新数据时强行修复。

## 一、数据与预测边界

- [ ] 搜索指数只表述为需求代理，不表述为真实出游意愿或因果变量；注明其可能受媒体事件与新闻传播影响。
- [ ] 日级验证明确为“已知当日天气、已知滞后搜索”的条件验证，不宣传为完全未知未来下的预测精度。
- [ ] 外部报道锚点只对地域、时间和统计口径同时匹配的记录计算误差；景区、行政区和度假区范围不同的记录只作合理性核验。
- [ ] 说明 2026 年天气与搜索为历史同日情景输入，而非已知真实未来值。
- [ ] 山海关宽区间与下界为零只解释为高不确定性警示，不用于常态配置或精确客流结论。
- [ ] 全市年度预测范围较宽时，摘要优先报告点预测与“高不确定性”结论，不突出上下界作为醒目数字。

## 二、资源优化与运营解释

- [ ] 论文主线只采用绝对资源规划模型；早期相对档位模型仅作为备选/附录，不引用其旧数字。
- [ ] 停车、接驳、人员结果均写作情景规划需求，不写作当地现有资源台账。
- [ ] 北戴河、海港—阿那亚、山海关的停车外溢写作 P+R、预约、错峰或限流的管理需求，不虚构新增停车供给。
- [ ] Q4 的阈值平台解释为离散车辆、班组、泊位档位的配置切换，不解释为连续边际效应。
- [ ] 相对成本和标准化损失不写作人民币、真实运营成本或问卷满意度；引用 `q3_parameter_basis_register.csv` 的参数边界。
- [ ] 不声称已完成 VOT 货币化或 CVaR；当前为离散情景优化与敏感性分析。

## 三、图表、正文与结果一致性

- [ ] 摘要、结论、正文、图注、表注中的所有数字与最新 `outputs` CSV 逐项一致。
- [ ] 所有“游客量”均标明其为官方年度统计、锚点约束估计或情景规划量三者之一。
- [ ] 问题二引用 `q2_daily_conformal_calibration_2026.csv` 与 `q2_summer_peak_range_2026.csv` 的最新区域校准结果。
- [ ] 问题三引用最新 `q3_absolute_resource_sensitivity_2026.csv`，并核对三区高压场景数值。
- [ ] 问题四引用 `q4_lambda_plateau_diagnostic_2026.csv`，呈现阈值切换而不是光滑曲线叙述。
- [ ] 旧 Markdown、旧 PDF、早期图表不作为提交版引用来源。
