# 问题四：情景扰动、鲁棒性与管理建议

以问题二日预测和问题三中心情景资源方案为基线，构造北戴河暑期大型文旅活动与山海关连续五日阴雨两类反事实场景。活动采用五日预热—峰值—余波脉冲；阴雨按连续日递进折减游客需求。每个受扰动日均比较固定基线方案的服务缺口与重新优化后的泊位、接驳、人员配置。

结果文件：`q4_event_counterfactual_2026.csv`、`q4_rain_counterfactual_2026.csv`、`q4_robustness_sensitivity_ranking.csv`。

建议保留两图一表：`q4_scenario_service_gap.png`、`q4_sensitivity_ranking.png` 和 `q4_baseline_reoptimization_summary_2026.csv`。管理建议应优先提升接驳可调度储备与活动预警，因为接驳分担率、活动强度的敏感性排序最高；阴雨情景则保持安全、排水、咨询和基础交通保障，并收缩可变接驳与服务班组。

## 可直接写入结论的管理建议

1. **活动预警与前置调度：** 活动日前两天开始监测活动热度和预售，若预测服务缺口超过 0.15，则提前申请外圈 P+R、接驳储备车和中班增援，而不是等活动日现场扩容。
2. **阴雨弹性与安全底线：** 连续阴雨时按日滚动缩减可变接驳和入口班组，但保留排水巡检、应急引导、咨询和无障碍交通的最低班组，避免单纯按客流下降比例裁撤。
3. **停车—接驳联动：** 山海关古城节点容量超限时，优先发布外围换乘和分时入城指引；不得将古城 2,225 位误作全区容量。北戴河活动日则优先保证旅游专线的最大发车间隔。
4. **网红片区精细治理：** 阿那亚等封闭式或预约型片区应建立停车、接驳、预约入园和酒店入住的统一日台账；模型建议以该台账校准情景容量与接驳分担率。

模型局限：日级游客规模仍是锚点约束估计；停车周转、车辆座位、人员效率和成本为情景参数；空间节点未覆盖全部私营停车资源。后续应接入停车诱导、调度日志、预约订单和活动预售数据，改为滚动小时级优化。

所有结论为情景规划模拟，不是对活动实际客流、降雨实际影响或景区成本的事实陈述。
