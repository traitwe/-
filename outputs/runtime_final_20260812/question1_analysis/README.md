# 问题一分析结果目录

所有地区日级量均为模型估计的相对旅游压力，而不是官方逐日真实游客数。

- `q1_city_annual_trend.csv`：官方全市国内游客年度趋势和残差。
- `q1_regional_pressure_decomposition.csv`：三区连续日压力的趋势、季节项和随机项。
- `q1_regional_season_classification.csv`：三区逐月淡、平、旺季标签。
- `q1_factor_strength.csv`：联合模型标准化关联强度排序。
- `q1_service_time_scenarios.csv`：日内服务时段证据；不含、也不推断逐小时游客计数。
- `q1_analysis_quality_report.json`：覆盖范围、单位及限制。
